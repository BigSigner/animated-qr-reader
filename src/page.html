Animated QR Reader

Source code

Read a sequence of QR codes with the camera and save the file they contain. The codes can arrive in any order.

Keep a copy of this page

Download the file and serve it on this computer. The reader is inside the file, so that server needs no network connection. Opening the file directly often blocks the camera.

Save the file in an empty folder, open a terminal in that folder, and run:

python3 -m http.server

Then open:

http://127.0.0.1:8000/animated-qr-reader.html

Formats
  • UR, including fountain codes such as crypto-psbt, from SeedSigner, Foundation Passport, Keystone, Blockstream Jade, Sparrow, and Krux.
  • BBQr from COLDCARD Q, Sparrow, and Nunchuk. Hex, base32, and zlib are read.
  • Specter p1ofN from Specter Desktop, Specter DIY, and Krux.
  • Legacy UR:BYTES/1ofN from older Specter and BTCPay.
  • BigSigner: gzip, then base64. The leading spaces are the part count plus one, and the trailing spaces are the part index.
  • A single code: a PSBT in binary, base64, base43, or hex, or any other file. Plain text is confirmed by a second read.

A PSBT is saved as .psbt. Other text is saved as .txt. Other bytes are saved as .bin.
